# Concept Taxonomy

Each concept in the learning graph belongs to exactly one category. The
categories run roughly in teaching order: foundations first, the capstone
and professional practice last.

| Category | TaxonomyID | Description |
|---|---|---|
| AI Foundations | FOUND | What AI, machine learning, deep learning, and generative AI are; history; how models are trained and used; where AI appears in mechanical engineering. |
| Python and Jupyter | PY | The Python language, Jupyter notebooks, NumPy, Matplotlib, and pandas: just enough programming to work with engineering data and models. |
| Engineering Data and Measurement | DATA | Sensors, data acquisition, units, measurement error, and the kinds of data engineers collect and clean. |
| Statistics and Probability | STAT | Descriptive statistics, probability distributions, correlation, uncertainty, and data bias. |
| Machine Learning Fundamentals | ML | Features and labels, regression, classification, clustering, train/test splits, overfitting, and evaluation metrics. |
| Neural Networks | NN | Artificial neurons, layers, activation functions, loss, gradient descent, and the scale of modern networks. |
| Generative AI and LLMs | GENAI | How large language models and other generative models work: tokens, transformers, training stages, context windows, hallucinations, agents. |
| Prompting for Engineering | PROMPT | Writing effective prompts for engineering work: structure, context, constraints, units, output formats, and iteration. |
| Verifying AI Output | VERIF | Checking AI answers with hand calculations, unit and order-of-magnitude checks, limiting cases, and trusted sources. |
| AI Coding Assistants | CODE | Using AI to write, explain, debug, and test Python for engineering calculations, plus documentation and version control. |
| AI in Design and Simulation | DESGN | The design process, optimization, generative design, topology optimization, CAD, simulation, and surrogate models. |
| AI in Manufacturing and Maintenance | MFG | Quality control, computer-vision inspection, additive manufacturing, predictive maintenance, anomaly detection, and digital twins. |
| Ethics and Professional Practice | PRAC | Engineering ethics, safety, accountability, intellectual property, privacy, academic integrity, and the capstone project. |
